# Golden data manifest

Generated by `generate.py` (Python stdlib, seed `20261023`; reruns are byte-identical). Row numbers are 1-based sheet rows, i.e. CSV record index + 1; a cell with embedded newlines still counts as one row. Machine-readable copy of every answer: `golden-data-ground-truth.json`. Money in the JSON is integer cents.

Upload note: import each CSV into its own tab. With Google Sheets' "Convert text to numbers, dates, and formulas" ON, Sheets will itself coerce some cells (e.g. `$1,234.50`, `12%`, `'42` loses the apostrophe and becomes text, `04/07/2026` is parsed by the spreadsheet locale). Turn it OFF to keep the raw mess exactly as listed here.

Data is grouped in region blocks in this order: North, South, East, West, Central; each block ends with a subtotal row. Revenue = round_half_up(qty x unit_price x (1 - discount)); Cancelled = 0; Returned = negative.

Normalisation rules that make the answers reproducible: region/category/status: lowercase, drop all whitespace; `&`/`and` equivalent; `canceled` = `cancelled`. DD/MM/YYYY is day-first. Excel serials count days from 1899-12-30. Treat `""`, `-`, `N/A`, `n/a`, `null`, `TBD` as null.
