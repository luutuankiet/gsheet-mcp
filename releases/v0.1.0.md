# v0.1.0

## First release

gsheet-mcp is an MCP server for Google Sheets, running on Cloud Run at
`https://gsheet-mcp.cloud.run` behind Google sign-in. An agent starts from a
sheet URL with `scan_sheet`, reads with `read_range`, `grep_sheet`,
`query_range` and `render_range`, and changes the sheet with `write_cells`,
`edit_sheet`, `run_sheet_script` and raw `batch_update` requests. Writes go
through a plan and a stale-write check, and come back with a receipt.

## The gsheet CLI

`@luutuankiet/gsheet` 0.1.0 is on npm. `pull_tables` hands a sheet's tables
to it, and `npx @luutuankiet/gsheet` loads them into a local DuckDB file for
SQL, then pushes edits back through `upload_slot` and `write_cells`. The
server itself never parses rows.

## Also

- `install_skill` returns the gsheet-mcp skill and its cookbook for clients
  without a skill loader.
- `docs/deploy.md` is the self-hosting checklist: `scripts/deploy`, the
  OAuth client and the custom domain.
