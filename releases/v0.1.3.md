# v0.1.3

## Fewer sign-ins from Claude

The server's own access token now lasts 7 days instead of about an hour.
Claude's connector asks for a new sign-in after an expired token instead of
refreshing it, so a short token meant a sign-in prompt every hour or after an
account switch. The server keeps refreshing the Google token itself. Google
still ends a testing app's refresh token after 7 days, so a sign-in is needed
once a week while the OAuth app stays in testing.

Existing sign-ins get the longer token at their next refresh; nobody needs to
sign in again because of this release.
